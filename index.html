Les 3 métriques

🎯 Silhouette

Cohésion + séparation d'un point
↑ plus élevé = meilleur
Plage : −1 → +1

📉 Davies-Bouldin

Similarité entre clusters
↓ plus faible = meilleur
Plage : 0 → ∞

📈 Calinski-Harabasz

Dispersion inter / intra
↑ plus élevé = meilleur
Plage : 0 → ∞

Silhouette — un point, deux distances

s(i) = (b − a) / max(a, b)
  • a(i) : distance moyenne à son propre cluster
  • b(i) : distance moyenne au cluster voisin le plus proche
  • ≈ +1 : très bon · ≈ 0 : chevauchement · < 0 : mal affecté
Clique sur « Étape suivante »

Silhouette interactive : K = 2 → 5

  • K trop petit : clusters fusionnés (b ≈ a)
  • K trop grand : un vrai groupe est coupé en deux
  • Pic de silhouette = K naturel

Quel K choisiriez-vous ? K=3 (3 groupes réels) — vérifie en augmentant la dispersion.

Davies-Bouldin — clusters trop semblables ?

DB = moyennei maxj≠i (Si+Sj) / d(ci,cj)
  • S = dispersion interne (cercle pointillé)
  • d = distance entre centres (flèche)
  • Proches → DB élevé · Séparés → DB faible
Glisse « sep » pour éloigner les clusters.

Davies-Bouldin : configurations A vs B

A → DB faible = meilleur · B → DB élevé = moins bon. Déplace les clusters avec « sep ».

Calinski-Harabasz — inter / intra

CH = (B / (k−1)) / (W / (n−k))
  • B : dispersion entre clusters
  • W : dispersion dans les clusters
  • Élevé = compacts et bien séparés

En code : les 3 métriques (scikit-learn)

# 1. Préparer les données (important : mettre à la même échelle)
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import (silhouette_score,
    davies_bouldin_score, calinski_harabasz_score)

X = StandardScaler().fit_transform(df)   # df = âge, revenu, fréquence, montant

# 2. Clustering avec un K donné
labels = KMeans(n_clusters=3, n_init=10, random_state=42).fit_predict(X)

# 3. Les métriques : toutes prennent X et labels (pas de vérité terrain)
silhouette_score(X, labels)          # -1 → +1 : plus haut = meilleur
davies_bouldin_score(X, labels)      # 0 → ∞  : plus bas  = meilleur
calinski_harabasz_score(X, labels)   # 0 → ∞  : plus haut = meilleur
💡 Aucun label requis : seules les données X et les clusters trouvés labels sont utilisés.

En code : choisir le meilleur K

import pandas as pd

rows = []
for k in range(2, 6):                      # K = 2, 3, 4, 5
    labels = KMeans(n_clusters=k, n_init=10, random_state=42).fit_predict(X)
    rows.append({
        "K": k,
        "silhouette": silhouette_score(X, labels),
        "davies_bouldin": davies_bouldin_score(X, labels),
        "calinski_harabasz": calinski_harabasz_score(X, labels),
    })

res = pd.DataFrame(rows).set_index("K")
print(res.round(2))

# Meilleur K selon chaque métrique
print("Silhouette  :", res["silhouette"].idxmax())          # max
print("Davies-B.   :", res["davies_bouldin"].idxmin())      # min
print("Calinski-H. :", res["calinski_harabasz"].idxmax())   # max
⚠ Si les K diffèrent : visualise les clusters (PCA/t-SNE) avant de décider.
